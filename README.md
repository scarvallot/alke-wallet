# Alke Wallet 💰

**Una billetera digital moderna y segura para gestionar tus activos financieros.**

## 📋 Sobre el Proyecto

**Alke Wallet** es una aplicación web de billetera digital desarrollada como parte del **Módulo 2: Fundamentos del Desarrollo Front-end**.

El objetivo principal es ofrecer a los usuarios una **experiencia intuitiva, segura y funcional** para administrar sus finanzas personales de forma digital.

## ✨ Funcionalidades Principales

- **Autenticación de usuarios** (Login / Registro)
- **Gestión de contactos** (Agenda para transferencias rápidas)
- **Realizar transacciones** (Envío y recepción de dinero)
- **Historial de movimientos** y balance en tiempo real
- **Interfaz moderna y responsive**

## 🎯 Objetivo del Proyecto

Desarrollar un **front-end dinámico** que resuelva la necesidad de los usuarios de gestionar sus activos financieros de manera **segura, conveniente y confiable**, ofreciendo una experiencia de usuario fluida y profesional.

## 🛠️ Tecnologías Utilizadas

- **HTML5**
- **CSS3** (Flexbox, Grid, Responsive Design)
- **JavaScript (ES6+)**
- **Manipulación del DOM**
- **Consumo de APIs** (Async/Await, Fetch)
- **Diseño UI/UX** enfocado en experiencia financiera
